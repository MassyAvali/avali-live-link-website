💜 Privacy Policy

Avali Live Link

Effective Date: November 19, 2026

1. Introduction

Avali Live Link ("the Bot", "we", "our") is a Discord application that provides automated Twitch livestream notifications to Discord communities.

This Privacy Policy explains what information the Bot processes, why it is needed, and how users and server administrators can manage it.

2. Information We Collect

To provide Twitch notifications, Avali Live Link stores the following configuration information:

  • Discord server IDs.
  • Discord notification channel IDs.
  • Twitch usernames configured by server administrators.
  • Custom notification messages.
  • Twitch stream IDs used to prevent duplicate alerts.
  • Notification timestamps used for the 8-hour cooldown.

The Bot does not require users to provide passwords, payment information, or personal Discord messages. It is not designed to collect the contents of ordinary Discord conversations.

3. How Information Is Used

Stored information is used to:

  • Monitor configured Twitch channels.
  • Send livestream notifications to selected Discord channels.
  • Customize announcement messages.
  • Prevent duplicate notifications.
  • Enforce an 8-hour notification cooldown.
  • Maintain server configurations between bot restarts.

4. Third-Party Services

Avali Live Link interacts with Discord and Twitch to provide its functionality.

The Bot uses the Twitch API to retrieve publicly available stream information, including livestream status, stream titles or categories when available, and streamer profile information.

Notifications are delivered through Discord. Information processed by these services is also subject to their respective privacy policies.

5. Data Storage and Retention

Bot configuration information is stored in a local database operated by the Bot's administrator.

Configuration data is retained while the relevant Twitch notification configuration remains active, unless it is removed by a server administrator or through an authorized deletion request.

The Bot does not use stored configuration information for advertising or sell it to third parties.

6. Data Deletion

Discord server administrators with the required permissions can remove saved Twitch configurations using the following commands:

  • /twitch clear - Removes a specific Twitch streamer configuration.
  • /twitch clearall - Removes all Twitch streamer configurations associated with the current Discord server.

Removing a configuration deletes its associated saved settings, stream ID, and cooldown timestamp from the active database.

8. Children's Privacy

Avali Live Link is intended for use in accordance with Discord's and Twitch's applicable age requirements. The Bot is not designed to knowingly collect personal information from children.
